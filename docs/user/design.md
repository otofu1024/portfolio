# Design Notes

ユーザーからのデザインに関する要望をまとめたファイルである。

## デザインコンセプト

学生エンジニアとしての学習姿勢m技術への関心、個人の雰囲気が伝わる**シンプルなポートフォリオ**にする。

派手な演出より、読みやすさ、余白、情報整理を重視する。

## 使用するカラーコード
- ゆずイエロー（Yuzu Yellow）: #F9D030 - ゆずの果皮を思わせる、鮮やかで温かみのあるメインカラー。
- ゆずリーフ（Yuzu Green）: #84A93E - ゆずの葉や未熟な青ゆずを表現した、自然で落ち着いた緑色。
- クリームホワイト（Cream White）: #FDFBF2 - ゆずの果肉や和紙のような、目に優しい背景用オフホワイト。
- チャコールブラウン（Charcoal Brown）: #4A3E31 - ゆずの枝や土を連想させる、文字色に最適な引き締まるこげ茶色。
- ソフトアンバー（Soft Amber）: #FFAA00 - 完熟したゆずや柚子茶のような、アクセントとなる温かいオレンジ色。
