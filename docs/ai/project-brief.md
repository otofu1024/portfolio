# プロジェクト概要

## 目的

このプロジェクトは、ミニマルな個人ポートフォリオサイトです。1ページの中で、自己紹介、スキル、制作物、連絡先を簡潔に伝えることを目的としています。
現在の内容は `docs/user/about_me.md` と `docs/user/design.md` にあるユーザー提供情報を反映しています。

## 目指す体験

サイト全体は、シンプルで読みやすく、軽量な印象にします。見た目の複雑さよりも、明確なテキスト、素直な導線、編集のしやすさを優先します。
学生エンジニアとしての学習姿勢、分散システムやWeb技術への関心、個人の雰囲気が伝わることを重視します。

## 完成条件

- Hero、About、Skills、Projects、Contact の各セクションがあること。
- Vite上で動く単一ページのReactアプリとして動作すること。
- デスクトップ幅とモバイル幅の両方で読めるレイアウトになっていること。
- コンテンツは `src/App.tsx` のローカル配列とテキストを編集して更新できること。
- `src/assets/icon.png` のプロフィールアイコンがHeroセクションで表示されること。
- `docs/user` 配下のユーザー指示を、今後の内容更新時の優先参照元にすること。
- Tailwind CSSを使い、余白、文字、リンク、罫線、控えめな面表現を中心にしたモダンな見た目にすること。
- 実装変更後に `npm run lint` と `npm run build` が通ること。

## 非目標

- ダークモードは実装しない。
- グラデーションは使わない。
- カードベースのビジュアルシステムは使わない。
- 装飾的な影は使わない。
- ルーティングや複数ページ化は行わない。
- バックエンドやAPI連携は追加しない。
- 問い合わせフォーム送信機能は追加しない。
- CMSやコンテンツ生成パイプラインは追加しない。
- アニメーションライブラリは追加しない。
- Tailwind CSS以外の新しい依存関係は、明示的に依頼されない限り追加しない。

## コンテンツの初期方針

ユーザーから正式な内容が提供されるまでは、以下は仮の内容で問題ありません。

- 名前
- プロジェクト名と説明
- プロジェクトURL
- SNSやプロフィールURL
- 短い自己紹介文
